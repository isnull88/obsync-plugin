# ObSync

ObSync — плагин для Obsidian. Плагин синхронизирует хранилище между устройствами через сервер ObSync.

В этом репозитории есть только сборки плагина. Исходный код закрыт.

## Что нужно

- Obsidian на ПК, iPhone или iPad.
- Плагин BRAT.
- Сервер ObSync и ссылка для подключения от владельца сервера.

## Установка

1. В Obsidian откройте «Настройки» → «Сторонние плагины».
2. Найдите и установите плагин BRAT.
3. Включите плагин BRAT.
4. Откройте «Настройки» → BRAT.
5. Нажмите «Add beta plugin».
6. Введите адрес репозитория: `isnull88/obsync-plugin`.
7. Нажмите «Add plugin».
8. Откройте «Настройки» → «Сторонние плагины».
9. Включите плагин ObSync.

## Подключение

1. Откройте «Настройки» → ObSync.
2. Подключите устройство по ссылке от владельца сервера.

## Обновление

Начиная с версии 0.3.3, плагин обновляется сам. Плагин проверяет подпись каждой версии и ставит только подписанные версии.

Для проверки вручную откройте «Настройки» → ObSync и нажмите «Проверить обновление».

## Если обновление не работает

1. Откройте «Настройки» → ObSync.
2. Нажмите «Вернуть предыдущую версию».

Если плагин не запускается:

1. Откройте «Настройки» → BRAT.
2. Найдите ObSync в списке плагинов.
3. Нажмите «Update».
4. Перезапустите Obsidian.
